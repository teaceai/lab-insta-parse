# Project 3 - *BeReal Pt. 2*

Submitted by: **Trina Tabassum**

**BeReal Pt. 2** is a photo sharing app that introduces Parse persistence, post time and location metadata, and a 24-hour feed viewing constraint where users cannot view other posts until they upload their own.

Time spent: **4** hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] User can launch camera to take photo instead of photo library
  - [x] Users without iPhones to demo this feature can manually add unique photos to their simulator’s Photos app
- [x] Posts have a time and location attached to them
- [x] Users are not able to see other users’ photos until they upload their own.

The following **optional** features are implemented:

- [ ] Posts have a comment section, which displays the commenter’s username and comment context
- [ ] User receives notification when it is time to post

The following **additional** features are implemented:

- [x] Implemented pull-to-refresh on feed to reload posts
